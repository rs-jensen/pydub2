# Security

Only the latest release gets security fixes.

## Reporting a problem

Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting instead: open the Security tab of this repository and click "Report a vulnerability". Only the maintainer can read what you send there.

Say which version you use, what you did and what happened. A file that triggers the problem helps a lot.

## What to expect

I will answer within a week. If the report is a real vulnerability I will work on a fix and tell you
when a release is out, and I will credit you in the release notes unless you would rather not be named.
Please give me a reasonable time to fix it before you share the details.

If you run pydub2 on files from other people, see [docs/untrusted-files.md](docs/untrusted-files.md).
